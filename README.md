# Sokoban — README

Классическая головоломка Сокобан, реализованная на Lua с использованием фреймворка Solar2D. Проект создан с помощью ИИ (DeepSeek, GigaChat) и предназначен для платформ Android, Windows и HTML5.

## О проекте

**Sokoban** (яп. кладовщик) — игра, в которой игрок перемещает ящики по лабиринту, чтобы расставить их на целевые позиции.

### Технологический стек

* **Движок:** Solar2D (бывший Corona SDK) — кроссплатформенный 2D-фреймворк.
* **Язык:** Lua.
* **Архитектура:** Composer (управление сценами), модульная структура.
* **Алгоритмы:** BFS (поиск в ширину) для управления касаниями.

## Структура проекта

Проект организован по принципу разделения данных, логики и интерфейса:

```text
project/
├── main.lua              -- Точка входа, запускает сцену меню
├── scenes/
│   ├── menu.lua          -- Главное меню
│   ├── levelSelect.lua   -- Выбор уровня с превью
│   └── game.lua          -- Основная игровая логика
└── modules/
    ├── data.lua          -- Статические данные: карты уровней
    ├── gameState.lua     -- Состояние игры (позиции, счет)
    ├── save.lua          -- Сохранение/загрузка в JSON
    └── undo.lua          -- История ходов (откат)
```

## Особенности реализации

1. **Управление:** Изначально реализовано кнопками, затем добавлено управление касаниями откуда-куда переместить ящик. При выборе ящика касанием алгоритм BFS находит кратчайший путь для его перемещения. Если перемещение невозможно, ящик мигает красным.
2. **Ориентация:** Реализована альбомная ориентация для удобства игры на сенсорных экранах.
3. **Иконка:** Сгенерирована ИИ (1024x1024), нарезана через `makeappicon.com`.
4. **Отказ от лишнего:** В текущей версии нет профиля игрока, музыки и сложных спрайтов для сохранения производительности и простоты кода.

## Инструкция по запуску

1. Установите Solar2D.
2. Создайте новый проект.
3. Скопируйте файлы в соответствующие директории.
4. Запустите симулятор (`File -> Simulate`) или соберите APK/AAB/EXE (`File -> Build`).

## Добавление новых уровней

Уровни хранятся в `modules/data.lua` в виде массива строк. Символы означают:

* `#` — стена
* ` ` (пробел) — пол
* `.` — целевая точка
* `$` — ящик
* `@` — игрок
* `\\\*` — ящик на цели
* `+` — игрок на цели

Пример уровня:

```lua
map = {
    "#####",
    "# @ #",
    "# $ #",
    "#####"
}
```

### Конвертер уровней Microban

Для импорта уровней с сайта `users.bentonrea.com` используется Python-скрипт `Microban.py`.

```bash
python Microban.py Microban.txt data.lua
```

Пример входного файла `Microban.txt`:

```
; 1
####
# .#
# ###
#\\\*@ #
# $ #
# ###
####
```



Пример выходного файла `data.lua`:

```

local data = {

&#x20;   levels = {

&#x20;       {

&#x20;           name = "Microban 1",

&#x20;           map = {

&#x20;               "######",

&#x20;               "# .###",

&#x20;               "#  ###",

&#x20;               "#\*@  #",

&#x20;               "#  $ #",

&#x20;               "#  ###",

&#x20;               "######",

&#x20;           }

&#x20;       },

&#x20;   }

}



return data

```
